## 🚀 Проекты

### 👾 [UmbraNet](https://github.com/X-302-X/UmbraNet)

**Защищённый DNS, диагностика и восстановление сети на Windows — в одном окне.**

Настольная программа на PySide6, которая объединяет три вещи:

- **движок обработки трафика** — переключаемые стратегии для TLS/QUIC, лежат в одном месте и меняются в один клик;
- **собственный DNS-сервер с шифрованием** — DoH / DoQ / DNSCrypt с кэшем, защитой от подмены ответов (детект «заглушек» провайдера), автопереключением на самого быстрого провайдера и резервом, когда не отвечает никто;
- **диагностика и «починка»** — проверка утечек DNS, откат сетевых настроек одной кнопкой и отдельный watchdog-процесс, который вернёт DNS даже после краша.

<sub>Python · PySide6 · WinDivert · GPLv3 · 4 темы оформления</sub>
